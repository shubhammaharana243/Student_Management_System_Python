# 🎓 Student Management System Using Python

A simple, menu-driven **Student Management System** built with Python to manage student records through a command-line interface (CLI). This project demonstrates core Python concepts, data structures, functions, and file handling.

## 📌 About the Project

The Student Management System allows users to add, view, search, and delete student records. It also provides unique student names and a summary of the total number of students and their average marks.

Student data is stored in a text file (`students.txt`) using Python file handling.

## ✨ Features

- ➕ **Add Student:** Add a student's name, age, and marks.
- 📋 **View Students:** Display all stored student records.
- 🔍 **Search Student:** Search for students by name.
- 🗑️ **Delete Student:** Remove a student record.
- 👤 **Unique Names:** Display unique student names.
- 📊 **Student Summary:** Show the total number of students and average marks.
- 💾 **File Handling:** Save student records to a text file.
- 📂 **Load Data:** Load student records from a file when the program starts.
- 🖥️ **Menu-Driven Interface:** Navigate through options using the command line.

## 🛠️ Technologies Used

- **Language:** Python 3
- **Data Structures:** Lists, Tuples, and Sets
- **Concepts:** Functions, Loops, Conditional Statements, and Exception Handling
- **Storage:** Text File Handling

## ⚙️ Getting Started

### Prerequisites

- Python 3 installed on your computer.
- Git installed (optional, for cloning the repository).

### 1. Clone the Repository

```bash
git clone https://github.com/shubhammaharana243/Student_Management_System_Python.git
```

### 2. Navigate to the Project Folder

```bash
cd Student_Management_System_Python
```

### 3. Run the Program

If your Python file is named `main.py`, run:

```bash
python main.py
```

If your file has a different name, replace `main.py` with the actual filename.

## 🚀 How to Use

After starting the program, a menu appears with the following options:

| Option | Action |
|---|---|
| 1 | Add Student |
| 2 | View Students |
| 3 | Search Student |
| 4 | Delete Student |
| 5 | Show Unique Names |
| 6 | Show Summary |
| 7 | Save and Exit |

Choose an option by entering its corresponding number and follow the on-screen instructions.
